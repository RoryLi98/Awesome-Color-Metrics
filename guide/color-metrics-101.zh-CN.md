# 色差指标入门：配准与非配准图像的颜色、对比度测量

[English](color-metrics-101.md) · [简体中文](color-metrics-101.zh-CN.md)

给定参考图像与待测图像，例如 ISP 输出、重拍、压缩或编辑结果，我们希望知道**颜色和对比度改变了多少**。准确对应的像素可以直接比较；即使只残留一个像素的错位，许多指标也会把边缘变化计入色差。本文解释如何选择指标、解释结果，并用自己的图像检查它们。[主列表](../README.zh-CN.md)提供论文与实现，[`shift_vs_cast.py`](shift_vs_cast.py)提供可运行的对照实验。

## 1. 用一个公式描述问题

```text
I₂(x) = P[I₁(T(x))] + n
```

| 符号 | 含义 | 评测中的角色 |
|:--|:--|:--|
| I₁、I₂ | 参考与待测图像 | 比较对象 |
| T | 平移、单应、镜头畸变、视差等几何变化 | 希望排除的干扰 |
| P | 增益、颜色矩阵、色调曲线、饱和度与局部对比度变化 | 希望测量的变化 |
| n | 噪声 | 需要估计的干扰 |

“已配准”意味着同一坐标确实指向同一场景点。SIFT + RANSAC、ECC 或光流仍可能残留亚像素至像素误差，在深度边缘处通常更大。

## 2. 先明确要回答什么

1. **看起来有多大差异？** FLIP、ColorVideoVDP、LPIPS、DISTS、MS-SWD、CD-Net 等提供感知分数。
2. **颜色改变了多少，具体怎样改变？** ΔE00、明度/彩度/色相分解，以及拟合的颜色矩阵和色调曲线提供更容易归因的结果。

一个分数不能区分白平衡误差、饱和度与对比度变化。工程评测可以用感知分数交叉检查，再以可归因量作为主要结论。

## 3. CIELAB 与 ΔE

- 两幅图像使用相同的颜色定义和参考白：sRGB 解码为线性 RGB，再转 XYZ、CIELAB。sRGB 通常为 D65，图卡数据常为 D50，需要时使用 Bradford 等色适应变换。
- **ΔE*ab（CIE76）**是 CIELAB 欧氏距离；**CIEDE2000（ΔE00）**重新加权明度、彩度与色相。报告时必须说明公式，饱和颜色上的数值可能相差很大。
- 分别报告 **ΔL***（明度）、**ΔC***（彩度）、**ΔH***（色相）。相同 ΔE00 可以来自不同误差；分项能帮助定位曝光、饱和度或白平衡问题。这些分项的具体定义也应说明，不能把所有分解都视为可直接相加。
- 图卡报告中的 **ΔC00** 常指去掉明度项的差异，仍包含色相；它与单纯的彩度差 ΔC* 不同。
- HDR 或宽色域可考虑 ΔE ITP、Jzazbz、CAM16-UCS，并说明亮度与适应条件；尚无适合所有 HDR 场景的统一模型。

均匀色块并排比较时，ΔE00 小于 1 常较难察觉，2–3 较明显，超过 5 通常很明显。这只是粗略解释，不能直接作为整图阈值：内容、背景和误差空间分布都会影响感知。

## 4. 对比度有多种定义

| 类型 | 测量方式 | 解释限制 |
|:--|:--|:--|
| 全局 | RMS（亮度标准差/均值）、以第 1/99 百分位代替极值的 Michelson | 噪声和锐化也会增大 RMS |
| 局部、分频带 | Peli 带限对比度：带通信号除以下一低频尺度的低通信号 | 每个尺度输出一张图 |
| 色调曲线 | 待测与参考亮度散点，拟合阴影/中调/高光斜率、黑电平、截断 | 最容易解释变化方向 |
| SSIM 对比度项 | 忽略稳定常数时为 2σxσy/(σx²+σy²) | 比率 0.6 与 1/0.6 都约为 0.88，无法区分提高或降低 |
| 可见性 | DRIM 的可见对比度丢失、增强与反转 | 不用于描述所有轻微色调曲线变化 |

## 5. 准确配准后报告什么

**颜色：** ΔE00 图及均值、中位数、p95、最大值、超阈值像素比例；ΔL*/ΔC*/ΔH* 图或统计；在线性 RGB 中拟合 `test ≈ curve(M · ref)`，即 3×3 颜色矩阵加逐通道单调曲线，报告组合变换及残差 ΔE00。可交替固定曲线拟合矩阵、固定矩阵拟合曲线，迭代 3–4 轮。

**对比度：** 色调曲线斜率、黑电平、截断，以及各频带 `σ_test / σ_ref` 图。平坦区域的 σ 接近零，应加掩膜排除。

即使配准也要处理以下问题：

1. **重采样改变对比度。** 插值是低通处理，一次双三次变换就可能改变最细频带几个百分点。两幅图应采用相同重采样，或单独量化其影响。
2. **颜色空间与白点。** 拟合矩阵前先线性化，保持参考白一致。
3. **截断。** 排除过曝与压黑区域，那里无法可靠估计 ΔE 或曲线斜率。
4. **噪声与锐化。** 单独报告最细频带，以免把它们解释为目标对比度变化。
5. **参数非唯一。** 曲线与矩阵能互相补偿，应报告它们在标准颜色集上的组合效果，而非仅解释矩阵单个元素。

## 6. 错位为什么会污染逐像素指标

同一图像平移一个像素，其逐像素 ΔE00 图就会出现边缘。距离非负，错位通常使均值增大，这是系统性偏差；增加图像数量不能自动消除。偏差随场景结构变化，真实色差越小，它占读数的比例可能越大。

**先聚合，再比较。** 先计算区域均值或分布，再求差异。宽度 W 的区域平移 d 时，边界交换的内容比例通常随 d/W 增长。以下为原英文指南在 scikit-image astronaut（512 像素）及脚本指定混合颜色/对比度变化下的示例：

| 平移 | 逐像素 ΔE00 | W=4 | W=16 | W=32 | W=128 | 整图均值 |
|--:|--:|--:|--:|--:|--:|--:|
| 0.25 px | 0.153 | 0.080 | 0.042 | 0.030 | 0.012 | 0.008 |
| 0.5 px | 0.311 | 0.160 | 0.083 | 0.060 | 0.024 | 0.016 |
| 1 px | 0.602 | 0.318 | 0.167 | 0.119 | 0.048 | 0.032 |
| 2 px | 0.930 | 0.609 | 0.331 | 0.238 | 0.096 | 0.062 |

表内是**伪信号比值 = 仅错位的读数 / 准确配准时真实变化的读数**，并非 ΔE00 绝对值。公式相同，只改变聚合顺序。该示例提示区域宽度可从预期残留错位的 16–32 倍起试；这不是普适保证。

区域越大，定位能力越弱，建议同时报告区域均值与 p95。全局增益、矩阵和缓慢变化的色调通常参数较少，因此聚合仍有用。线性变换可与线性 RGB 均值交换；拟合非线性色调曲线时优先低方差区域。

| 策略 | 示例 | 代价 |
|:--|:--|:--|
| A. 先配准后测量 | 变形 + 像素指标 | 插值损失与残留偏差 |
| B. 先聚合后比较 | 区域均值、直方图、MS-SWD | 丢失空间定位 |
| C. 容忍式匹配 | 邻域最小 ΔE、cPSNR、上下文匹配 | 也可能掩盖真实细小差异 |
| D. 参数模型拟合 | 在区域均值上拟合曲线与矩阵 | 模型之外的变化进入残差 |
| E. 联合估计 | 对 P 不敏感的 ECC 式配准 | 消除光度变化本身，不直接测量它 |

回答颜色如何改变时，可以采用 **B + D**：先获得较干净的区域样本，再拟合可解释模型。

## 7. 两个容易混淆的问题

**迟钝不等于稳健。** 局部归一化可能减弱某些整体光度变化；SSIM 对色偏的响应取决于通道和具体实现。原指南示例中，可见的通道增益色偏（ΔE00 约 3.4）只使 1−SSIM 改变 0.0024，约为一个像素平移响应的 1/56。某些纹理、Gram 矩阵及深度特征方法也可能忽略目标颜色变化。应同时报告指标对真实颜色变化及纯错位的响应。

**采样误差不只是错位。** 重拍显示器或印刷品会引入显示网格、光学模糊与传感器网格的交互。摩尔纹和混叠产生的颜色误差无法靠配准完全消除；可采用光学或数字低通，或避开高频区域。CameraVDP 展示了先校正相机几何、MTF、暗角与颜色，再评价显示设备的方法。

在受控图卡实验中读取色块中央，并向内缩进至少预期错位距离，可以避免色块边界的对应误差；这仍不能排除采样、光照、噪声等其他误差。

## 8. 色偏与平移对照实验

```bash
pip install numpy scipy scikit-image
python guide/shift_vs_cast.py my_reference.png
python guide/shift_vs_cast.py my_reference.png --shift 0.5
```

脚本生成混合真实变化、无颜色变化的平移、以及线性通道增益为 1.13/1.00/0.86 的纯白平衡色偏。下表沿用英文指南的 astronaut 示例；本次翻译没有重新运行这些实验。

| 指标 | 类别 | 伪信号（平移/真实变化） | 色偏/平移 |
|:--|:--|--:|--:|
| 逐像素 ΔE00 | pixel | 0.602 | 1.2 |
| 逐像素 RGB 夹角 | pixel | 0.542 | 1.3 |
| 1−SSIM | pixel | 0.718 | 0.02 |
| 区域均值 ΔE00（32 px） | shift | 0.119 | 6.9 |
| 1−直方图交集（Lab 16³） | free | 0.127 | 3.9 |
| √χ² 直方图（Lab 8³） | free | 0.223 | 2.2 |
| 整图均值 ΔE00 | free | 0.032 | 35 |
| 切片 Wasserstein（Lab） | free | 0.021 | 41 |
| Lab 各通道一维 Wasserstein | free | 0.022 | 43 |
| 颜色矩 | free | 0.011 | 42 |
| 色彩丰富度比率 | free | 0.010 | 204 |
| 平均 RGB 夹角 | free | 0.005 | 384 |

“色偏/平移”小于 1 表示可见色偏得分低于一个像素的错位，指标在该条件下难以排除几何干扰。直方图分箱与图像内容会改变数值；比例高也不代表保留了局部颜色信息。

原指南还记录过另一次 640×640 自然图像实验：MS-SWD 为 37；DeepDC 使用替代 VGG 权重，在四幅图上为 1.7–9.8；FLIP 为 1.8；DeepSSIM 使用替代权重，在四幅图上为 0.65–1.6；ColorVideoVDP 为 0.5；VSI 为 0.18；FSIMc 为 0.08；CW-SSIM 为 0.07。这些是不同条件下的示例，不能直接当作统一排行榜。使用 `--pyiqa msswd,fsim,vsi,cw_ssim,dists` 可在自己的数据上复查相关实现。对可见差异模型而言，平移本身可能可见，正是这类模型需要准确对应输入的原因。

## 9. 建议报告的结果

比较两个 ISP 或 ISP 与参考时，可报告：

1. 在标准颜色集（如 ColorChecker 24 色）上评估拟合组合变换的 ΔE00，描述系统性颜色变化，并说明区域拟合及残余错位条件。
2. 区域均值 ΔE00 的均值与 p95，以及区域尺寸，描述变化分布。
3. 区域均值的 ΔL*/ΔC*/ΔH*，说明变化类型。
4. 色调曲线斜率、黑电平、截断及各频带对比度分布距离。
5. 一个适合当前错位条件的感知交叉检查，如 MS-SWD。
6. 每个指标的噪声底：同条件重复拍摄或仅平移对照的读数；低于噪声底的差异不能可靠归因。

## 10. 如何选择

- 准确配准且需要归因：ΔE00 图与分项、曲线加矩阵、局部对比度比率。
- 准确配准且关注可见性：ColorVideoVDP、FLIP、HDR-VDP-3，并明确显示条件。
- 约一个像素的残余错位：区域均值与相同色差公式，搭配 MS-SWD 或 CD-Flow。
- 不同视角或相机：先核实内容重叠与分布假设，再考虑 Lab Wasserstein、MS-SWD、CD-Net；DISTS、DeepSSIM 等另做颜色敏感性检查。
- 受控场景：测试图卡、OECF、ISO 或 CPIQ 协议。
- 任何非配准评测：先做色偏与平移对照，再解释真实图像分数。
